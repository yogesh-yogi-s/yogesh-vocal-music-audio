# VMA welcome demo asset

`welcome-demo.vma` is a deterministic VMA V1 container generated by
`scripts/make_welcome_demo.py`. It contains two seconds of mono, 16-bit PCM at
22.05 kHz:

- Vocal stem: a pulsed 440 Hz synthetic square tone.
- Music / Instrumental stem: a continuous 220 Hz synthetic square tone.

The tones are generated mathematically and contain no recording, song, artist
performance, or third-party media. They are part of this MIT-licensed project.

V1 is used because the existing application serves its streams as ordinary PCM
WAV through the normal session playback endpoints. This avoids making the welcome
experience dependent on optional compressed-codec support while preserving the
frozen V1 binary contract.

Regenerate the asset from the repository root with:

```powershell
python scripts/make_welcome_demo.py
```

Expected output: 176,729 bytes, SHA-256
`a8b94eacbd48e294aff21ea181eadd72b56c497a35d5be3d295ebbc306fc7879`.
